# AI-Exercise-Form-Classification
The code shown in this repo is the model that was created for my final project in the course Applied Artificial Intelligence. The goal of this project was to use the data collected from a Raspberry Pi and SenseHAT and integrate that with an AI model so that it could provide live feedback on the form of four different exercises. The exercise form was filtered into two different results, either 'good' or 'bad'. To classify form, two machine learning models were evaluated: a Random Forest (RF) classifier, and a Multi-Layer Perceptron (MLP) neural network. Both models were selected due to their strong performance in time-series classification tasks and their ability to capture nonlinear relationships in motion data. The input to each model consisted of a 37-dimensional feature vector extracted from the segmented IMU windows. The MLP pipeline included a StandardScaler preprocessing step, followed by the NN model. Feature scaling was necessary to normalize the input data, ensuring that features with larger magnitudes did not dominate the learning process. Both models were trained and evaluated on the same feature set, allowing for a direct comparison of performance.The extracted features were used to train supervised ML models for exercise form classification. Rather than using a single model for all activities, separate models were trained for each exercise (push-ups, sit-ups, squats, and lunges). This approach allows each model to learn exercise specific motion patterns and improves classification performance for distinguishing between good and bad form. The dataset for each exercise was divided using a stratified 80/20 hold-out split, where 80% of the data was used for training, and 20% for testing. Stratification ensured that both “good” and “bad” form samples were proportionally represented in both sets, reducing bias and improving the reliability of evaluation results. During training, feature vectors derived from segmented IMU data were used as inputs to the models. The models were trained and compared for each exercise to identify the best-performing approach. 5-fold stratified cross-validation was applied on the training set during model development. The ROC AUC was used as the primary optimization metric, as it provides a robust measure of classification performance across different decision thresholds. Model performance was evaluated using several classification metrics, including accuracy, precision, recall, F-1 score, and specificity. Accuracy measures the overall proportion of correctly classified samples, while precision reflects how effectively the model avoids false positives. Recall evaluates the model’s ability to correctly identify true positives, and the F1-score provides a balanced measure of precision and recall, particularly useful when class distributions are uneven. Specificity measures the ability of the model to correctly identify true negatives. The evaluation results demonstrated strong model performance across all exercises. In particular, high specificity values indicated that the models rarely misclassified one form category as the other, suggesting clear separation between “good” and “bad” form patterns. Overall, the models were able to effectively learn the underlying structure of the motion data and generalize well to unseen test samples. The overall accuracy for this model for each exercise was Push-up - 92%, Sit-up - 95%, Squat - 93%, Lunge - 93%.
